# MoMo System (Console Version)

A C++ based command-line application that simulates mobile money (MoMo) transactions.

## 🚀 Features
- **Secure Authentication:** PIN-based access control with limited attempts.
- **Transaction Simulation:**
    - Transfer Money (MoMo to MoMo, Non-MoMo, Bank, etc.)
    - MoMoPay & Bill Payments
    - Airtime & Data Bundle purchasing
    - Cash Out with automatic fee calculation
- **Financial Tracking:** Balance inquiry and mini-statement history generation.

## 🛠 Prerequisites
- A modern C++ compiler (g++ recommended).
- Linux environment (tested on Kali Linux).
